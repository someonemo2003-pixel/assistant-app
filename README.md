# مساعدي

مساعد شخصي بالذكاء الاصطناعي لأندرويد. بتكلّمه بكلامك العادي، وهو بينفّذ.

## التسطيب
1. افتح صفحة **Releases** في الـ repo ده من الموبايل.
2. نزّل آخر ملف `.apk` وسطّبه. لو الموبايل سألك، اسمح بالتسطيب من المصدر ده.
3. افتح التطبيق، وادخل على ⚙️، وحط مفتاح API واحد على الأقل. مفتاح Gemini مجاني.

أي تحديث جديد بيتسطّب فوق القديم، وإعداداتك وذاكرتك بيفضلوا زي ما هما.

## المرحلة الحالية (0.1)
- شات بالكتابة، وبالعامية المصرية.
- أكتر من مزوّد بالترتيب (Gemini ← Groq ← OpenRouter): لو واحد خلص الحد بتاعه، ينقل للي بعده لوحده. وتقدر تضيف أي مزوّد بصيغة OpenAI من الإعدادات.
- ذاكرة محلية على الموبايل، وتقدر تشوفها وتعدّل فيها.
- أوامر: منبه، مؤقت، فتح تطبيق، تجهيز رسالة SMS، حفظ وبحث في الذاكرة.
- مفاتيح الـ API متشفّرة بـ Android Keystore.
